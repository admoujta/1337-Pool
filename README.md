## 📖 About

This repository documents my work during the **1337 Piscine**, the intensive selection and learning experience of the **42 Network**.

The Piscine is built around practice, autonomy, peer learning, evaluations, debugging, and continuous problem solving. My goal throughout this journey was not only to make the exercises work, but to understand **why they work** and build strong programming fundamentals.

> **Core objective:** write clean C code, master the Unix environment, strengthen algorithmic thinking, and develop disciplined debugging habits.

## ⚙️ Build & Run

Compile a C exercise with strict flags:

```bash
cc -Wall -Wextra -Werror file.c
```

Run the executable:

```bash
./a.out
```

For projects with a `Makefile`:

```bash
make
make clean
make fclean
make re
```

## 🔁 My Problem-Solving Workflow

```text
Read the subject
      ↓
Understand the constraints
      ↓

      ↓
```
